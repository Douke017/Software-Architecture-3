# HITO 3: Reflexión sobre el uso de IA y Prompting

## 3.1 – Análisis del prompt más efectivo
Identificar el prompt que mejores resultados les dio. ¿Cuál fue? ¿Por qué funcionó bien? ¿Qué tenía de claro o específico?

## 3.2 – Iteración y refinamiento del prompt
¿En algún prompt tuviste una respuesta incorrecta, vaga, incompleta o desalineada con tus expectativas? ¿Qué falló en la respuesta inicial? ¿Cómo ajustaste el prompt? ¿Qué mejoró en la nueva respuesta?
