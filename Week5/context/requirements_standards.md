# Estándares de Ingeniería de Requerimientos (NASA & IBM DOORS)

Cuando corresponda caracterizar requerimientos de arquitectura o desafíos de sistema:

1. **Requerimientos Funcionales (FR)**: Formulados de forma unívoca con identificadores tipo `[FR-001]` indicando la capacidad que el sistema debe proveer.
2. **Requerimientos No Funcionales (NFR)**: Formulados con métricas verificables `[NFR-001]` (ej. latencia p95 < 200ms, disponibilidad 99.99%, tiempo medio de recuperación MTTR < 2 min).
3. **Restricciones Arquitectónicas (CON)**: Identificadores `[CON-001]` delimitando límites técnicos o de negocio insalvables.
