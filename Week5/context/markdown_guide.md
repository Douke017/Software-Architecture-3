# Guía de Formato Markdown (Week 5)

Para garantizar un formato uniforme, legible e impactante en los informes técnicos de arquitectura:

1. **Encabezados Estructurados**: Usa `#` para título principal, `##` para secciones mayores (Hitos), `###` para subsecciones numéricas.
2. **Listas y Negritas**: Para cada punto técnico, utiliza negritas al inicio del elemento de lista (ej: `- **Concepto**: Descripción breve y rigurosa`).
3. **Tablas Sintéticas**: Utiliza tablas Markdown estándar cuando compares alternativas o resumas conceptos (ej. Síncrono vs Asíncrono, Acoplamiento Débil vs Fuerte).
4. **Cero Código de Aplicación**: No incluyas fragmentos de código fuente (Java, Python, JS, SQL). Limítate a diagramas PlantUML y explicaciones lógicas de arquitectura.
