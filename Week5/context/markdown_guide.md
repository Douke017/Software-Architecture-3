# Guía Estándar de Formato Markdown (Visual Standard)

- **Encabezados Claros**: Usa `#` para títulos principales, `##` para secciones y `###` para subsecciones.
- **Resaltados**: Usa **negrita** para términos clave y `código en línea` para comandos o nombres técnicos.
- **Tablas**: Formatea tablas de comparación de forma limpia con alineación explícita.
- **Listas**: Usa viñetas estructuradas para mejorar la legibilidad.
