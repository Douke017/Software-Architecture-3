# Guía Estándar de Formato Markdown (Strict Table & Clean Typography Standard)

Esta guía define las reglas de sintaxis imperativas para garantizar que todas las tablas y secciones de Markdown rendericen **100% parseables, limpias y sin roturas**.

---

## 1. Reglas Estrictas para Tablas Markdown

1. **FILAS DE UNA SOLA LÍNEA**: Toda fila de tabla DEBE ser una sola línea de código sin saltos de línea (ENTER) internos.
2. **DELIMITADORES DE COLUMNA**: Toda fila DEBE comenzar y terminar con `|`.
3. **SIN CARACTERES RESERVADOS**: Prohibido usar barras `|` dentro del texto de celdas (usar `&#124;` si es imprescindible).
4. **SIN BLOQUES DE CÓDIGO INTERNOS**: Prohibido insertar ` ``` ` o citas `>` dentro de celdas.

---

## 2. Reglas de Numeración Estándar

1. **NUMERACIÓN DESDE 1. (PROHIBIDO EMPEZAR EN 0.)**:
   - `1. Contexto y Dominio del Negocio QuickCart`
   - `2. Microservicios Candidatos`
   - `3. Decisiones Discutibles y Justificación`
   - `4. Explicación en Profundidad de Límites de Servicio`
   - `5. Análisis de Anti-Patrones y Evaluación de Riesgos`
   - `6. Lista de Verificación (Checklist)`
